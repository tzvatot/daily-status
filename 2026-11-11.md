# Daily Status - 2026-11-11

## Accomplishments
- Implemented the core conformance suite for [OSAC-7454](https://redhat.atlassian.net/browse/OSAC-7454) to provide a reusable foundation for defining, running, selecting, and reporting conformance checks across OSAC deployment areas. Prepared the implementation plan and validation documentation, confirmed the conformance tests and lint/format checks passed, and submitted [osac#2340](https://github.com/osac-project/osac/pull/2340) as a draft PR for review. Remaining work is review and merge.
- Investigated [OSAC-7635](https://redhat.atlassian.net/browse/OSAC-7635) and traced the Netris CA regression to [osac#2051](https://github.com/osac-project/osac/pull/2051), while confirming the main-branch correction had landed through [osac#2151](https://github.com/osac-project/osac/pull/2151). Determined that the 0.4 release candidates were cut before the correction, so they still lack the fix; closed the issue as Done with a post-0.4 resolution.
- Reopened [OSAC-7635](https://redhat.atlassian.net/browse/OSAC-7635) for a targeted release-0.4 backport and implemented the CA configuration correction without unrelated networking changes. Added regression coverage, validated the backport in a lab environment, and confirmed a virtual network provisioned successfully with certificate validation enabled. Submitted [osac#2383](https://github.com/osac-project/osac/pull/2383) as a draft PR for review; it remains unmerged.
- Restored the lab environment after validation, including test resources and the original automation configuration.

## Risks & Challenges
- The 0.4.0 release candidates remain affected by the Netris CA issue; the correction is expected only after 0.4.
- Both [osac#2340](https://github.com/osac-project/osac/pull/2340) and [osac#2383](https://github.com/osac-project/osac/pull/2383) remain draft PRs awaiting review and merge.
- The full unit suite still has 16 unrelated pre-existing failures, so it does not provide a completely clean signal; the targeted conformance and networking test suites passed.
- Lab validation initially encountered a credential-layout mismatch, which was resolved during the session and did not leave persistent impact.

## Key Effort
Primary focus was advancing the OSAC conformance suite foundation and resolving the release-0.4 Netris CA regression through a targeted backport and lab validation.
