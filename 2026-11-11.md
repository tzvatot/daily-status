# Daily Status - 2026-11-11

## Accomplishments

- Worked on [OSAC-7454](https://redhat.atlassian.net/browse/OSAC-7454) conformance suite core: ingested the story, produced a 17-case story testplan, and built out the suite core covering configuration, case selection, verdicts, reporting, and operability. All conformance tests pass (62 passed, 1 skipped) and linting is clean. Submitted a draft PR for review: [osac#2340](https://github.com/osac-project/osac/pull/2340).
- Triaged the Netris CA regression in [OSAC-7635](https://redhat.atlassian.net/browse/OSAC-7635): traced it to an earlier networking change, confirmed the fix is already on main via [osac#2151](https://github.com/osac-project/osac/pull/2151), and verified that the 0.4.0 release candidates were cut before that fix so they remain affected.
- Closed [OSAC-7635](https://redhat.atlassian.net/browse/OSAC-7635) as done with resolution "post 0.4", then reopened it to cover the 0.4 backport.
- Backported the Netris CA fix to the 0.4 release line in [OSAC-7635](https://redhat.atlassian.net/browse/OSAC-7635), adding regression coverage and doc updates. The full unit suite (1555 tests) and the relevant config-as-code tests pass, with linting and pre-commit clean. Submitted a draft PR for review: [osac#2383](https://github.com/osac-project/osac/pull/2383).
- Validated the backport on a lab cluster: the affected virtual network provisioned successfully through the networking jobs with certificate validation enabled and no TLS errors. Test resources were removed and the environment was restored afterward.
