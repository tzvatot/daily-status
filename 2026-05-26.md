# Daily Status - 2026-05-26

- Merged [fulfillment-service#584](https://github.com/osac-project/fulfillment-service/pull/584) — fix for value serialization in the custom JSON encoder.
- Built and verified catalog items demo on vmaas-dev for [OSAC-58](https://redhat.atlassian.net/browse/OSAC-58): created two catalog items ("Developer Sandbox" with locked fields and "Production Cluster" with editable fields and schema validation), tested cluster creation from both, validated input rejection and mutual exclusivity rules, and verified the full end-to-end demo flow from catalog items through controller reconciliation to AAP job launch. - Diagnosed and resolved a four-layer TLS/OAuth failure chain affecting the fulfillment controller and Authorino on vmaas-dev:
  - Fixed a CA bundle mismatch that prevented the controller from discovering the OAuth token endpoint (Keycloak was signed by a different CA than what the controller trusted).
  - Added newly required identity-provider configuration flags to the controller deployment to match the latest image.
  - Resolved an Authorino pod startup failure caused by a volume mount collision between the CA bundle and TLS certificate paths introduced by an operator update.
  - Corrected the Authorino CA trust path so that custom CAs are found by the Go TLS stack on RHEL-based images.
  - Result: controller is running stable, both demo clusters progressed to provisioning, and AAP jobs were triggered.
