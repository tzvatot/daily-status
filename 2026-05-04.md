## Risks & Challenges

- **Demo cluster not yet ready**: Two-node clusters require two healthy bare-metal agents, but one agent is stuck in an unbinding state requiring a physical host reboot. Either a one-node template or a reboot is needed to proceed.
- **Orphaned ManagedClusters still breaking RBAC**: Five orphaned ManagedClusters on vmaas-dev continuously reconcile RBAC resources, blocking a team member's access. These need to be deleted with elevated privileges.
- **DNS cleanup broken on cluster deletion**: The IAM user for Route 53 DNS is missing a required permission, causing the delete flow to fail at DNS cleanup. This is a separate blocker from the FQCN fix and affects all cluster deletions on vmaas-dev.
- **ESI resource leaks on force-delete**: Force-deleting ClusterOrders via finalizer removal bypasses AAP cleanup, leaving orphaned routers and agent labels in ESI. At least one stale router remains.
