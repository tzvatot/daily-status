# Daily Status - 2026-05-04

## Accomplishments

- **CaaS demo environment:** Re-published AAP templates after syncing to latest main (includes [osac-aap#274](https://github.com/osac-project/osac-aap/pull/274)). Verified that cluster templates no longer expose sensitive parameters directly, and confirmed cluster creation works with the new explicit secret-file flags.
- **Fixed osac-operator crash loop on vmaas-dev:** Diagnosed an informer cache sync timeout caused by missing RBAC permissions for the PublicIP resource. Patched the cluster role and updated the operator to the latest image — all controllers now syncing successfully.
- **Fixed AuthConfig tenant assignment:** Resolved a cluster creation failure where all service accounts were incorrectly assigned multiple tenants. Corrected the configuration so only the template-publisher service account receives cross-tenant access.
- **Fixed missing Ansible role reference:** Root-caused an AAP job failure to a short-name role reference introduced during the Netris work ([MGMT-23420](https://issues.redhat.com/browse/MGMT-23420)). Fixed by switching to fully-qualified role names, deployed and verified on vmaas-dev. PR [osac-aap#282](https://github.com/osac-project/osac-aap/pull/282) merged.
- **Cleaned up stale ESI routers:** Deleted 5 orphaned routers that had no matching cluster orders, freeing up router quota. Retried cluster creation — provisioning now progresses past router creation.

## Risks & Challenges

- **Blocked on agent availability:** Cluster provisioning fails because all bare-metal agents of the required resource class are bound to an existing cluster order. Need to either free those agents or relabel unassigned ones before the demo cluster can reach a ready state.
- **Potential router cleanup bug:** Four of the five orphaned routers had no matching cluster order in Kubernetes, suggesting that the finalizer-based cleanup may not reliably remove infrastructure when cluster orders are deleted before deprovisioning completes.

## Key Effort

Unblocking the CaaS demo environment on vmaas-dev by fixing a series of cascading issues — operator crashes, tenant misconfiguration, missing Ansible role references, and router quota exhaustion.
