# Daily Status - 2026-05-04

## Accomplishments
- **CaaS demo environment:** Re-published AAP templates after [osac-aap#274](https://github.com/osac-project/osac-aap/pull/274) was merged. Verified that sensitive template parameters (pull secret, SSH key) were removed and cluster creation works using the new explicit file-based approach.
- **Fixed osac-operator crash loop on vmaas-dev:** Diagnosed a controller cache sync timeout caused by missing RBAC permissions for the PublicIP resource. Patched the cluster role and updated the operator to the latest image — all controllers now syncing successfully.
- **Fixed AuthConfig tenant assignment:** Cluster creation was failing because all service accounts were incorrectly assigned to multiple tenants. Corrected the configuration so only the template-publisher account gets cross-tenant access. Successfully created a new demo cluster after the fix.
- **Fixed Ansible role resolution failure:** AAP jobs were failing because a role was referenced by short name instead of its fully-qualified collection name, introduced during the Netris integration ([MGMT-23420](https://issues.redhat.com/browse/MGMT-23420)). Submitted and merged [osac-aap#282](https://github.com/osac-project/osac-aap/pull/282) with the fix, deployed to vmaas-dev and verified it resolves the issue.
- **Identified stale ESI router cleanup needed:** After the role fix, cluster creation hit a router quota limit. Identified 5 stale routers (out of 10) with no matching cluster orders that need to be deleted to free capacity.
