# Daily Status - 2026-05-04

## Accomplishments
- **CaaS demo environment updated:** Re-published AAP templates with [osac-aap#274](https://github.com/osac-project/osac-aap/pull/274) changes, removing hardcoded template parameters so credentials are now passed via explicit CLI flags instead.
- **Fixed osac-operator crash loop on vmaas-dev:** Diagnosed missing RBAC permissions for the PublicIP resource and patched the ClusterRole to restore all controller syncing.
- **Fixed AuthConfig tenant assignment:** Corrected multi-tenant service account configuration that was incorrectly granting shared-tenant access to all service accounts, unblocking cluster creation.
- **Fixed broken Ansible role resolution ([osac-aap#282](https://github.com/osac-project/osac-aap/pull/282)):** Root-caused AAP job failures to a short role name introduced in a Netris commit ([MGMT-23420](https://issues.redhat.com/browse/MGMT-23420)); fixed by using fully qualified collection names. PR merged and deployed.
- **Cleaned up stale ESI resources on vmaas-dev:** Deleted 5 orphaned routers to free quota, cleaned stale labels from agents, force-deleted 6 stuck ClusterOrders blocked by a DNS IAM permission gap, and restored the environment to a clean state with 2 free agents.
- **Diagnosed agent-to-ESI registration gap:** Identified that two candidate agents are not registered in ESI Ironic, and found two alternative agents that are both ESI-registered and hardware-compatible for the demo cluster.
- **Fixed broken RBAC caused by orphaned ClusterRoleBindings:** Force-deleting ClusterOrders left orphaned RBAC resources referencing non-existent ClusterRoles, which broke API server authorization for a team member. Identified all 23 orphaned bindings and 13 orphaned roles for cleanup.
- **Reviewed and approved [fulfillment-service#481](https://github.com/osac-project/fulfillment-service/pull/481)** (installation guide) — all prior review findings addressed.
- **Reviewed and approved [osac-aap#268](https://github.com/osac-project/osac-aap/pull/268)** (Netris CaaS fixes) after confirming the Netris API merge-style PUT behavior.
- **Reviewed [osac-aap#279](https://github.com/osac-project/osac-aap/pull/279)** ([MGMT-24176](https://issues.redhat.com/browse/MGMT-24176) — BMH-based agent import) — posted findings on silent update skipping, missing job template settings, and broken local testing docs.
- **Created a `/slack-read` command** for reading and summarizing Slack threads directly from Claude Code.

## Risks & Challenges
- **Demo cluster not yet ready:** Multiple cascading issues (role resolution, router quota, agent ESI registration, RBAC breakage) have delayed the CaaS API demo recording. Two remaining agents need label cleanup and approval before retrying.
- **DNS cleanup blocked by IAM gap:** The cluster delete workflow fails at the Route 53 DNS step because the DNS manager service account is missing a required IAM permission — this is a separate blocker from the now-fixed role resolution bug, and will leave DNS records orphaned on cluster deletion until resolved.
- **Orphaned resource cleanup still in progress:** 23 ClusterRoleBindings and 13 ClusterRoles from force-deleted clusters still need to be removed to fully restore RBAC health.

## Key Effort
