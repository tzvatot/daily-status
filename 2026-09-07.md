# Daily Status - 2026-09-07

## Accomplishments

- **Investigated one-worker HyperShift cluster availability issue** ([OSAC-4441](https://redhat.atlassian.net/browse/OSAC-4441)): Diagnosed why a single-worker CI cluster could not reach a healthy state — infrastructure services required HA replicas that cannot schedule on one node. Traced the root cause to a standalone deployment overlay that injects a highly-available infrastructure policy, overriding the CI template's single-replica fallback. Applied an immediate configuration workaround and verified that newly created clusters now use the correct single-replica policy. A fix for the standalone deployment recipe's default configuration is still pending.
- **Retested [OSAC-4441](https://redhat.atlassian.net/browse/OSAC-4441) Story 1.02 semantic sub-stage feedback after [osac#767](https://github.com/osac-project/osac/pull/767) merge**: Deployed the merged operator image to the validation environment and created a fresh test cluster. Confirmed the first observed lifecycle feedback reflects the new semantic sub-stages. Monitoring is ongoing through the remaining provisioning transitions to terminal ready state.
- **Reported cluster-storage finalizer retention bug to storage working group**: After deleting a test cluster, the backing order remains stuck in a deleting state because the storage finalizer is not removed, even though all other cleanup (HyperShift teardown, automation job, feedback) completed successfully. Shared reproduction steps and evidence with the storage team. Root cause is likely a missed reconciliation event during deletion; investigation is with the storage team.
- **Corrected Jira dependency links for [OSAC-4441](https://redhat.atlassian.net/browse/OSAC-4441)**: Fixed four reversed dependency relationships so that OSAC-4441 correctly blocks its downstream epics ([OSAC-4443](https://redhat.atlassian.net/browse/OSAC-4443), [OSAC-4444](https://redhat.atlassian.net/browse/OSAC-4444), [OSAC-4445](https://redhat.atlassian.net/browse/OSAC-4445), [OSAC-4446](https://redhat.atlassian.net/browse/OSAC-4446)).
- **Reviewed stall detection PR** [osac#783](https://github.com/osac-project/osac/pull/783): Confirmed the fix correctly preserves stalled status across reconciliations until the provisioning stage advances. All tests and linting pass. Requested Riccardo's review.
- **Implemented [OSAC-4441](https://redhat.atlassian.net/browse/OSAC-4441) Story 1.04 — provisioning transition events**: Built Kubernetes events that fire when a cluster order transitions between provisioning sub-stages, enters a stalled state, or begins deletion. Includes duplicate suppression and full unit test coverage. Opened draft [osac#785](https://github.com/osac-project/osac/pull/785), stacked on the stall detection PR. Awaiting review and CI.
