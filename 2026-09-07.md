# Daily Status - 2026-09-07

## Accomplishments

- **Investigated single-worker HyperShift cluster availability:** Diagnosed why a one-worker hosted cluster could not reach available state — guest infrastructure services (ingress, image registry, monitoring) required HA replicas that couldn't schedule on a single node. Traced the root cause to the standalone deployment overlay injecting a HighlyAvailable infrastructure policy that overrides the CI template's SingleReplica fallback. Applied an immediate configuration workaround and verified that a replacement cluster correctly received SingleReplica policies. A fix for the standalone deployment recipe's default configuration remains open. ([OSAC-4441](https://redhat.atlassian.net/browse/OSAC-4441))

- **Merged [osac#767](https://github.com/osac-project/osac/pull/767):** PR was approved by Riccardo and merged.

- **Deployed and retested Story 1.02 on the merged image:** Built and deployed the post-merge operator image to the test environment, confirmed the previous test cluster reached full availability, then created a fresh cluster to validate semantic sub-stage feedback from the merged code. The first observed transition reported the expected initial sub-stage. Monitoring through remaining transitions is still in progress. ([OSAC-4441](https://redhat.atlassian.net/browse/OSAC-4441))

- **Reported cluster-storage finalizer retention bug:** After deleting a test cluster, the backing order remained stuck in Deleting due to an unremoved storage finalizer, even though all HyperShift resources and automation jobs completed successfully. Shared the issue and reproduction steps with the storage working group on Slack. The root cause likely involves the deletion event not reliably triggering storage reconciliation. Investigation by the storage team is pending.

- **Corrected Jira dependency links for [OSAC-4441](https://redhat.atlassian.net/browse/OSAC-4441):** Fixed four reversed dependency relationships so that OSAC-4441 correctly blocks [OSAC-4443](https://redhat.atlassian.net/browse/OSAC-4443), [OSAC-4444](https://redhat.atlassian.net/browse/OSAC-4444), [OSAC-4445](https://redhat.atlassian.net/browse/OSAC-4445), and [OSAC-4446](https://redhat.atlassian.net/browse/OSAC-4446).

- **Reviewed [osac#783](https://github.com/osac-project/osac/pull/783) (stall detection):** Reviewed the updated PR, confirmed the stalled-status persistence fix works correctly across reconcile cycles, and verified all tests and linting pass. Asked Riccardo for review; awaiting his feedback.

- **Implemented Story 1.04 — transition events:** Added Kubernetes events emitted on provisioning sub-stage transitions and deletion, with duplicate suppression. All tests pass including new unit tests for the event recording logic. Opened draft [osac#785](https://github.com/osac-project/osac/pull/785), stacked on the stall detection PR. Awaiting review and CI. ([OSAC-4441](https://redhat.atlassian.net/browse/OSAC-4441))
