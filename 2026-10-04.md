## Risks & Challenges

- **Primary blocker for [OSAC-4441](https://redhat.atlassian.net/browse/OSAC-4441):** The CaaS agent VM enters a boot-loop at 55% post-installation, rebooting into the discovery ISO instead of the installed disk and preventing the worker from joining; this blocks the test from reaching its event assertions and has been observed on both blade environments
- **Recurring NTP/DNS validation failures:** The InfraEnv NTP fix is applied as a live patch and is lost on each environment rebuild, causing repeated provisioning failures; it must be persisted in the agent setup scripts to stop recurring as a blocker
- **`10.6.76.209` environment remains broken:** The fulfillment-service floating image tag moved ahead of the Helm chart; a stable install requires pinning the image to a known-good digest or waiting for a chart update
