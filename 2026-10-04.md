## Risks & Challenges

- **CaaS worker VM boot loop (karim04, 10.6.76.209):** After the Assisted Installer completes worker installation, the VM reboots into the discovery ISO instead of the installed disk, preventing the worker from joining. A boot order fix has been identified but is not yet validated on a clean run; this is the definitive unresolved blocker on karim04.
- **Agent NTP and DNS validation failures (10.6.76.208):** The CaaS agent cannot reach a valid NTP server or resolve hosted-cluster DNS during provisioning, causing validation to fail and the worker to stall. The NTP configuration applied to the provisioning environment is a live patch that will be lost on the next environment rebuild; it has not yet been persisted to the setup script.
- **karim04 blade (10.6.76.209) environment is broken:** The fulfillment service image tag is floating and has drifted ahead of the Helm chart; the environment should not be used for E2E testing until reinstalled with a pinned image version.
