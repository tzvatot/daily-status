## Risks & Challenges

- **karim04 blade SNO environment is broken** — The `fulfillment-service` image/chart version skew causes CrashLoopBackOff on all fulfillment pods. The binary unconditionally initializes Kafka regardless of Helm configuration, making automated chart installation fail. Recommended fix is to pin the image to a known-good digest before reinstalling, or wait for the chart to be updated to match the new image API.
- **CaaS lifecycle test on Dan's environment is blocked** by a stale agent allocation from a previous failed order. The stale namespace must be cleaned and the agent re-registered before the test can proceed.
