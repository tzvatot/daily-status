# Daily Status - 2026-09-06

## Accomplishments

- Merged [osac#646](https://github.com/osac-project/osac/pull/646) for [OSAC-4441](https://redhat.atlassian.net/browse/OSAC-4441) — order-independent PROGRESSING condition derivation for ClusterOrder feedback. All CI checks passed, PR received LGTM and approval.
- Validated the PROGRESSING condition lifecycle end-to-end on a real OSAC caas-ci deployment (4 test scenarios), confirming correct stage derivation through ControlPlaneCreated → ControlPlaneAvailable → Ready on a live HyperShift control plane boot.
- Resolved six infrastructure blockers during deployment validation: Metal3/Ironic not deployed on platform-None clusters, BMH registration failing due to HTTPS vs HTTP mismatch, missing pull secret and RBAC for the AAP controller, network backend defaulting to ESI/OpenStack instead of the CI-appropriate backend, agent label mismatch between host type UUID and name, and etcd requiring single-replica mode on single-node OpenShift.
- Implemented sub-stage reason derivation for [OSAC-4441](https://redhat.atlassian.net/browse/OSAC-4441) Story 1.02 (finer-grained provisioning progress reporting) and submitted draft [osac#767](https://github.com/osac-project/osac/pull/767) for review.

Review feedback was addressed in follow-up commits; re-review is pending.
