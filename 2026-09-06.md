# Daily Status - 2026-09-06

## Accomplishments

- Merged [osac#646](https://github.com/osac-project/osac/pull/646) for [OSAC-4441](https://redhat.atlassian.net/browse/OSAC-4441) — order-independent cluster order feedback condition mapping. PR passed all CI checks (unit, integration, e2e across caas/bmaas/vmaas, linting, CodeQL), received LGTM and approval, and was merged.
- Validated the PROGRESSING feedback behavior on a real OSAC caas-ci deployment (host karim04), confirming that the feedback controller correctly derives the furthest lifecycle stage as the cluster progresses through control plane creation and availability — matching the expected order-independent behavior introduced in the PR.
- Set up and validated a full real-deployment test environment: deployed OSAC via Helm, registered a bare-metal worker agent through Metal3/Ironic, and ran a full hosted cluster lifecycle through AAP — proving end-to-end that the PR image works correctly in a real OSAC stack.
- Resolved six deployment blockers during environment setup:
  - Deployed Metal3/Ironic by creating the missing Provisioning CR (required on platform-type-None clusters).
  - Fixed bare-metal host registration by correcting the BMC address scheme to use HTTP instead of HTTPS for the sushy-emulator.
  - Created the missing pull-secret credential and granted the AAP service account the necessary RBAC to access it.
  - Switched the network backend to bypass OpenStack dependencies not present in the CI environment.
  - Fixed agent selection by aligning the agent label with the expected host type identifier format.
  - Switched the etcd availability policy to single-replica to allow the control plane to form quorum on a single-node cluster.
