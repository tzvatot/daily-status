# Daily Status - 2026-09-06

## Accomplishments

- Merged [osac#646](https://github.com/osac-project/osac/pull/646) for [OSAC-4441](https://redhat.atlassian.net/browse/OSAC-4441) — order-independent ClusterOrder feedback condition mapping. All CI checks passed, PR was approved and merged.
- Validated the merged changes on a real caas-ci deployment (host karim04), running four test scenarios (T1–T4) that confirmed the PROGRESSING condition correctly advances through provisioning stages (`ControlPlaneCreated` → `ControlPlaneAvailable`) on a live OSAC environment with actual HyperShift control plane boot. The T3 full-lifecycle test passed end-to-end with the control plane fully up and READY condition reporting True.
- Resolved six deployment blockers during the real-environment validation: missing Provisioning CR preventing Ironic/Metal3 from deploying, BMC connection using HTTPS instead of HTTP for the virtual BMC, missing pull secret and RBAC for AAP, network backend defaulting to ESI/OpenStack instead of the CI-compatible backend, agent label mismatch between host type UUID and name string, and etcd requiring three replicas on a single-node cluster. Each was diagnosed and fixed to unblock the validation.
- Set up bare-metal agent registration on the test environment — worker VM provisioned, registered as an approved agent, and available for cluster creation.
- Implemented [OSAC-4441](https://redhat.atlassian.net/browse/OSAC-4441) Story 1.02 — sub-stage reason derivation for provisioning progress (e.g., preparing infrastructure, control plane starting, workers joining). Submitted draft [osac#767](https://github.com/osac-project/osac/pull/767) for review.
- Reviewed [osac#767](https://github.com/osac-project/osac/pull/767) — identified one important issue (sub-stage reason can regress to a less-advanced state on transient condition reads, unlike the monotonic behavior in Story 1.01) and three suggestions (humanization drift risk, import alias inconsistency, test gaps). Feedback was addressed by a follow-up session that committed and pushed fixes; re-review of those changes is still pending.
