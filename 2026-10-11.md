# Daily Status - 2026-10-11

## Accomplishments
- **[OSAC-5508](https://redhat.atlassian.net/browse/OSAC-5508) — CI Netris certificate validation:** Disabled certificate validation for CI environments (BMaaS and full-chart) to unblock Netris connectivity in CI pipelines. Rebased and submitted [osac#1475](https://github.com/osac-project/osac/pull/1475); awaiting refreshed integration-test results. VMaaS E2E suite has failures across multiple test categories; a retest was triggered and a known-issue check is in progress.
- **Quarterly connection:** Submitted quarterly connection.
- **[OSAC-5972](https://redhat.atlassian.net/browse/OSAC-5972) — Deployed validation matrix:** Ran a comprehensive validation matrix for Netris CA support against a live environment using [osac#1520](https://github.com/osac-project/osac/pull/1520). All targeted scenarios passed: HTTP and HTTPS with certificate validation disabled, expected negative-test failures for self-signed and SAN-mismatch cases, DHCP/IPAM discovery after provisioning, full BMaaS/BareMetalHost provisioning, and a positive HTTPS run with a trusted private CA and correct certificate identity. One cleanup item remains: removing or replacing the temporary lab certificate used during testing.
- **[OSAC-5972](https://redhat.atlassian.net/browse/OSAC-5972) — Implementation and design gap review:** Compared the Jira acceptance criteria, [osac#1520](https://github.com/osac-project/osac/pull/1520), and the enhancement proposal. Confirmed that core acceptance criteria are met or demonstrated by the live validation. Identified gaps not yet addressed: production-mode enforcement that rejects insecure certificate settings, ConfigMap lifecycle and authorization controls, launch-input policy enforcement across all launch paths, canonical inventory guard coverage, and several test scenario gaps. The PR gate is not yet green due to a missing label and open code review feedback requiring more robust test assertions.
