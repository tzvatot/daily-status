# Daily Status - 2026-05-07

- Resolved OAuth integration issue between the fulfillment controller and Authorino — the root cause was an incorrect issuer URL in the AuthConfig, which caused Authorino to time out connecting to the Keycloak JWKS endpoint
- Fixed tenant assignment in JWT authentication so the controller could properly reconcile against the API
- Applied the updated ClusterOrder CRD from [osac-operator](https://github.com/osac-project/osac-operator) to include required fields that were being silently dropped by Kubernetes
- Cleaned up stale cluster data in the database — purged orphaned clusters left behind by force-deleted orders and reset failed cluster states

## Key Effort
