# Daily Status - 2026-05-07

- Fixed the fulfillment-controller OAuth and Authorino integration issue (continued from yesterday): the root cause was an incorrect issuer URL in the AuthConfig pointing to the wrong port, causing Authorino to time out when connecting to the Keycloak JWKS endpoint

- Applied the updated ClusterOrder CRD from osac-operator, which was missing required fields that Kubernetes was silently dropping

- AAP job ran successfully through most of the deployment pipeline (L2/L3 networking, agents, floating IP, DNS, HostedCluster creation) before failing at cluster bootstrap due to an MTU probe timeout — this is an infrastructure/bare-metal network issue, not an application code problem
