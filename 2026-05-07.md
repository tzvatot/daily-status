# Daily Status - 2026-05-07

## Accomplishments
- Resolved OAuth integration issue between the fulfillment controller and Authorino — the root cause was an incorrect issuer URL in the AuthConfig, which caused Authorino to time out connecting to the Keycloak JWKS endpoint
- Fixed tenant assignment in the AuthConfig so JWT-authenticated requests receive valid tenant values, unblocking controller reconciliation
- Applied the updated ClusterOrder CRD from [osac-operator](https://github.com/osac-project/osac-operator) to include previously missing fields that Kubernetes was silently dropping
- Cleaned up stale cluster data in the database left behind by force-deleted orders, and reset cluster state to allow the controller to proceed
- Controller successfully created a ClusterOrder with all required fields populated
- AAP job ran the full provisioning flow end-to-end (L2/L3 networking, agents, floating IP, DNS, HostedCluster creation, MetalLB ingress) — confirming all code and config fixes are working correctly
- AAP job ultimately failed at cluster bootstrap due to an MTU probe timeout — this is an infrastructure-level networking issue (ESI/bare-metal), not an application code problem

## Risks & Challenges
- Cluster provisioning is blocked by an MTU probe failure during bootstrap, likely caused by ESI VLAN/network configuration — needs investigation before retrying

## Key Effort
