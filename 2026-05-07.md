# Daily Status - 2026-05-07

## Accomplishments
- **Resolved OAuth integration issue with fulfillment controller**: Fixed the Authorino AuthConfig issuer URL that was pointing to the wrong port, which caused Authorino to time out when connecting to the Keycloak JWKS endpoint. OAuth token flow now works end-to-end and the API successfully returns clusters.
- **Fixed tenant authorization in JWT auth**: Corrected the AuthConfig tenant expression so that JWT-authenticated requests receive valid tenant assignments, resolving the "tenant can't be assigned" error during cluster updates.
- **Updated ClusterOrder CRD to latest version**: Applied the updated CRD from [osac-operator](https://github.com/osac-project/osac-operator) which was missing required fields — Kubernetes had been silently dropping them from submitted resources.
- **Cleaned up stale cluster data**: Purged orphaned clusters from the database that were left behind by force-deleted orders, and reset cluster status to allow the controller to proceed.
- **Controller successfully created a ClusterOrder** with all required fields populated. The associated AAP job is running and has passed L2/L3 networking, agent registration, floating IP, DNS, and HostedCluster creation stages.
