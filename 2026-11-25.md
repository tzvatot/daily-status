# Daily Status - 2026-11-25

## Accomplishments
- Scoped [OSAC-7455](https://redhat.atlassian.net/browse/OSAC-7455) for conformance test layers: profiles will run serially inside a per-run test Tenant, with parallel execution explicitly marked out of scope.
- Tracked down and fixed a redaction bug in the already-merged conformance plan output, where sensitive plan fields were being printed unredacted. Since the bug belonged to the earlier ticket, the fix was moved off the wrong branch, rebased, retested, and submitted for review as [osac#2662](https://github.com/osac-project/osac/pull/2662).
- Restored the OSAC-7455 branch to a clean state and cleaned up stale worktrees and branches left over from previously merged work.
- Decided, with user sign-off, that no design document changes are needed for OSAC-7455 and the merged enhancement proposal stays as-is.
- Moved the conformance runner tests into the conformance test tree and added a dedicated CI unit test leg so they run in CI, submitted as [osac#2569](https://github.com/osac-project/osac/pull/2569). The PR has full maintainer and working-group approval and its new unit test leg is green; merge is gated on the remaining required integration and end-to-end checks.
- Reviewed [osac#2647](https://github.com/osac-project/osac/pull/2647) covering tenant default networking readiness reporting, drafting a review with only minor and suggestive findings, and reviewed and commented on [osac#2592](https://github.com/osac-project/osac/pull/2592) covering agentless network cleanup, subnet validation, and error handling.
- Validated a real conformance run on the blade environment against the lab cluster, confirming the reporting, diagnostics, and verdict behavior, and used it to demonstrate the suite end to end.
- Changed the conformance verdict rule so a plan with no blocking tests is treated as passing, rebuilt and re-ran the demo to confirm a conformant result, and submitted the change as [osac#2667](https://github.com/osac-project/osac/pull/2667).
- Remaining on OSAC-7455: implementing the outstanding workstreams (client support, scratch cluster setup, component phases, profiles with Tenant handling, cleanup and leftovers, tests) plus two carry-over documentation items.
- Remaining on the reviews: the [osac#2647](https://github.com/osac-project/osac/pull/2647) review has not yet been posted.

## Risks & Challenges

- [osac#2667](https://github.com/osac-project/osac/pull/2667) has open design decisions: an informing-only plan now reports conformant even when its informing test fails, and it is unclear whether a selected profile should still show as required-but-skipped on a conformant report.
- The merged design and test plan contradict the new behavior for plans with no blocking tests, and that contradiction needs resolution before merge.
- Review feedback on [osac#2647](https://github.com/osac-project/osac/pull/2647) is drafted but not yet posted, pending a decision on whether to request changes or comment only.
- Unresolved decisions on OSAC-7455 scope and carry-over documentation items could delay implementation if not settled soon.

## Key Effort
