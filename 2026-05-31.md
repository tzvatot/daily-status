# Daily Status - 2026-05-31

## Accomplishments

- Implemented a reference-based exception for unpublished catalog item visibility in [fulfillment-service#595](https://github.com/osac-project/fulfillment-service/pull/595) — tenants can now retrieve unpublished catalog items that are still referenced by their existing clusters or compute instances. Reverted creator-based visibility per reviewer feedback, added tests, and pushed updates. PR awaiting further review.

- Conducted a gap analysis of four Jira user stories ([OSAC-997](https://redhat.atlassian.net/browse/OSAC-997), [OSAC-999](https://redhat.atlassian.net/browse/OSAC-999), [OSAC-1002](https://redhat.atlassian.net/browse/OSAC-1002), [OSAC-1007](https://redhat.atlassian.net/browse/OSAC-1007)) against the defined OSAC personas. Key finding: Tenant Admin is missing from all four tickets, and Cloud Provider Admin is missing or ambiguous in all four. [OSAC-1002](https://redhat.atlassian.net/browse/OSAC-1002) has the most impactful gap — the admin side of catalog management directly contradicts the personas document's role definitions. Drafted replacement user stories for [OSAC-1002](https://redhat.atlassian.net/browse/OSAC-1002) and sent to Avishay for review; remaining tickets still to be addressed.

- Investigated why [osac-test-infra#44](https://github.com/osac-project/osac-test-infra/pull/44) (catalog items E2E tests) is still in draft — it depends on [fulfillment-service#595](https://github.com/osac-project/fulfillment-service/pull/595) being merged and deployed. Posted a comment on the PR explaining the dependency. Compute instance catalog item tests still need to be added.

- Reviewed and approved [fulfillment-service#604](https://github.com/osac-project/fulfillment-service/pull/604), a Keycloak version upgrade — clean version bump with no issues found.

- Resolved all 8 automated review threads on [osac-workspace#23](https://github.com/osac-project/osac-workspace/pull/23) (PR previously merged).

- Fixed the vmaas-dev fulfillment-service outage caused by an expired CA certificate in the trust bundle. Discovered three separate CAs were needed in the bundle, rebuilt it, and restarted all affected pods — all five fulfillment pods now running. Still need to create an organization for Juan's related PR ([fulfillment-service#603](https://github.com/osac-project/fulfillment-service/pull/603)), which was blocked on this fix.
