## Risks & Challenges
- **Blocked on DNS domain mismatch:** the hosted cluster base domain is auto-derived with an extra prefix while the external access domain is not configurable in the chart at all, so the agent resolves a different name than the one published to cloud DNS. There is no DNS sync controller in the environment. Root cause is that the prior environment relied on manual overrides that were lost in a wipe and are not captured in the CI profile.
- **Blocked on NTP sync failure:** the worker VM cannot reach any time source because the discovery environment has no additional NTP sources configured and the setup tooling does not set them. This was also previously configured by hand and never documented.
- Both blockers must be corrected (domain alignment plus NTP source configuration) before the e2e run can proceed; the current order remains stuck with the control plane up but agent validation failing.
- Broader concern: multiple environment settings depend on undocumented manual configuration, making the test environment fragile to teardown/rebuild cycles.
